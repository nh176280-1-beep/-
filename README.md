# 한눈에 시세 v2 — 조건별 최신 가격 비교

[앱 열기](https://daegu-meat-prices-nh176280.satinycandy2.chatgpt.site)

직원이 외부에서 필요한 품목의 공개 가격을 확인하는 앱입니다. 로그인 없는 공개 조회 정책을 유지합니다. 전체 목록 갱신과 조회 기록 열람은 기존 ChatGPT 소유자만 가능합니다.

## 다운로드

[최신 v2 ZIP — 앱 소스·배포 빌드·저장 가격 CSV](downloads/price-board-v2-20261020.zip) (약 5MB). Windows 설치형 앱은 아닙니다. 압축 해제 후 `앱열기.url`로 온라인 앱을 열 수 있습니다.

## v2에서 달라진 점

- **조건별 원본 조회:** 축종·부위·등급·냉장/냉동·추가 검색어로 금천미트와 일품한우를 병렬 조회합니다. 원본 한 페이지(금천 250개/일품 200개)를 받아 명시한 조건을 적용합니다. 다음 원본 페이지로 계속 조회할 수 있으며, 첫 페이지만을 전체 결과로 표시하지 않습니다.
- **판매처 독립 처리:** 한쪽 원본이 실패해도 다른 쪽의 성공 결과를 제공합니다.
- **확인 상태와 시각:** 원본 성공, 최근 확인 결과(15초 재사용), 마지막 성공 사본, 저장 목록 대체, 실패를 구분합니다. 실패했다고 과거 확인 시각을 현재 시각으로 바꾸지 않습니다.
- **마지막 성공 결과 DB 저장:** 동일 조건의 요청을 합치고, 원본 장애 시 마지막 성공 사본을 제공합니다. 사본이 없으면 저장 목록으로 대체하면서 최신 결과가 아님을 표시합니다.
- **조건별 가격 범위:** 부위·등급·보관·축종·성별로 묶고, kg 단가만 비교합니다. 1+와 1++, 꽃등심과 등심, 1++(7)과 1++(9)를 같은 그룹으로 합치지 않습니다. 범위는 조회 결과 기준이며 전체 재고 최저가가 아닙니다.
- **선택 상품 상세 비교:** 최대 4개 상품의 가격·중량·총액을 나란히 보고, 선택한 상품만 상세 조회해 생산일·유통기한·원산지를 확인합니다. 일품한우의 실제 상세 날짜를 검증했습니다. 원본 HTML에 없는 정보(금천미트 일부 상세 포함)는 추정하지 않습니다. 상세 확인과 가격 확인 시각은 별개입니다.
- **관심 품목:** 익명 방문자별 저장을 유지하며, 실시간 조회에서 찾은 상품도 저장 목록에 없더라도 관심 목록에 보존합니다.
- **조회 기록·요청 제한:** 원본 검색·상세 조회 결과를 30일 기록하고 관리자만 볼 수 있습니다. 직원 실명 추적은 하지 않습니다. 조회·상세·관심 저장에 횟수 제한과 요청 크기 검증이 있습니다.
- **전체 목록 개별 갱신:** 금천·일품을 각각 시작하고 이어갑니다. 한 판매처의 작업이 다른 판매처 작업을 막지 않습니다. 원본 페이지는 최대 4개씩 병렬 처리합니다.

## 실제 가격 데이터와 한계

초기 스냅샷은 2026-10-20 수집한 실제 공개 가격 60,250건입니다(금천 49,819 / 일품 10,431).
금천 공개·유효 단위 확인 불가 716건 제외, 일품 원본 표시와 실제 목록 차이 142건은 일부 수집 상태로 기록합니다.
초기 데이터는 `lib/seed.ts`에 압축 저장하고, 활성 가격·실시간 사본·관심 품목·작업 상태는 D1에 보관합니다.

조건별 최신 조회에는 전체 6만 건 갱신을 기다릴 필요가 없습니다. 전체 목록 갱신은 보조 기능이며, 현재 화면이 후속 작업 요청을 보내므로 창을 닫으면 멈출 수 있습니다. 진행 상태는 보존됩니다. 자동 정기 전체 갱신은 설정하지 않았습니다.

부위·보관은 원본 상품명/분류 표기에서 구분하고, 금천 등급은 원본 API의 등급 필드를 사용합니다. 일품 등급은 원본 상품명 표기에서 추출합니다. 미표기는 임의 추정하지 않습니다. 동일 부위·등급이어도 원산지·브랜드·중량·생산일은 다를 수 있으므로 동일 상품 최저가라고 단정하지 않습니다.

원본 장애 또는 클라우드 IP 접근 제한 시 최신 조회가 실패할 수 있습니다. 이때 사본의 확인 시각과 오류를 표시합니다. 조회 후 가격·재고가 바뀔 수 있으므로 주문 전 원본을 확인하세요.

## 개발·검증

Node.js 24.5 이상(권장 24 LTS)과 npm:

```sh
npm ci
npm test
npx tsc --noEmit
npm run check:sources
npm run build
```

`check:sources`는 실제 원본을 조회합니다. 나머지 테스트는 격리된 데이터와 메모리 SQLite로 실행합니다. 캐시/장애 대체/시각 보존, 요청 합치기, 조건 필터, 실시간 관심 품목, 상세 날짜, 판매처별 작업 격리를 검증합니다.

Vinext/Cloudflare Workers와 D1 `DB` 바인딩을 사용합니다. `drizzle/`의 기존 0000 및 추가 0001 마이그레이션을 순서대로 적용하세요. 기존 사이트의 소유자 설정은 보존해야 하며, 새 환경의 관리자 설정·DB 초기 적재는 별도로 필요합니다. Windows 설치형 앱이 아닙니다.

## 파일과 배포

- `shared/live-source.js`: 원본 검색·상세 정보, robots.txt와 URL 검증
- `shared/conditions.js`: 조건 구분·비교 그룹
- `lib/live.ts`: 영구 사본·요청 합치기·제한·조회 기록
- `lib/data.ts`: 전체 저장 목록·관심 품목
- `lib/collect.ts`: 판매처별 전체 수집
- `app/board.tsx`: 최신 조회·저장 조회·상품 비교 화면

`.openai/hosting.json`은 기존 Sites 식별 정보를 보존합니다. 다른 사이트에 기존 ID로 배포하지 마세요. 비밀번호·토큰·쿠키·운영 소유자 ID를 소스나 ZIP에 넣지 않습니다. DB 사본과 직원/방문자 관심 품목은 소스 ZIP에 자동 포함되지 않습니다.
