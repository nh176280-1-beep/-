## v2의 잘못된 비교 수정

v2는 금천 검색어에 ‘냉장’을 넣어 상품명에 그 글자가 없는 원료육을 누락시키고 소포장 상품을 조회할 수 있었습니다. 일품의 ‘아래등심’도 일반 ‘등심’으로 잘못 구분했습니다. v2의 해당 가격 범위를 도매 원료육 시세로 사용하면 안 됩니다.

v3는 아래와 같이 수정했습니다.

- **금천:** 원본 분류 트리에서 국내산 한우 거세/암소 등 원료육 그룹과 부위의 최하위 카테고리를 선택합니다. 상품 목록 API에 등급·보관 필터를 전달합니다. 이름에 ‘냉장’이 없어도 원본 보관 필드가 냉장이면 조회합니다. 세절·낱개·소포장 그룹은 사용하지 않습니다.
- **일품:** 원본 그룹→부위→등급 카테고리를 조회하고 전체 목록 페이지를 검증합니다. 아래등심→아랫등심, 알목심→목심 같은 명시한 별칭만 정규화합니다. ‘등심’ 원본 카테고리에 포함된 꽃등심·윗등심·아랫등심은 별도 그룹으로 유지합니다.
- **비교:** 축종·성별·세부 부위·등급·보관·원료육 형태가 같은 것만 묶습니다. 다른 부위는 합치지 않으며, 상대 판매처에 일치하는 부위가 없으면 직접 비교 불가라고 표시합니다. 1++의 근내지방 7/8/9 정보가 있으면 구분합니다.
- **범위 검증:** 첫 페이지만 시세로 표시하지 않습니다. 각 요청의 원본 건수와 상품번호를 대조하면서 페이지를 이어받습니다. 반복 페이지·누락·서버 오류·카테고리 밖 상품은 성공으로 표시하지 않습니다. 범위가 너무 크면 조건을 좁히라는 오류를 반환합니다.
- **상세:** 금천 상품 API에서 제조일·소비기한·원산지·이력번호를 가격과 함께 받아 보관합니다. 일품은 선택 상품의 상세 페이지에서 날짜를 확인합니다. 없는 값은 추정하지 않습니다.
- **이전 사본 차단:** v2 검색 결과와 초기 이름 기반 스냅샷을 v3 비교의 장애 대체값으로 사용하지 않습니다. 같은 v3 조건의 검증된 마지막 성공 사본만 재사용합니다. 그 사본이 없으면 가격 비교 결과를 비워 두고 오류를 표시합니다. 저장 전체 목록은 별도 참고 탭으로 남습니다.

- 관리자 조회 기록(30일), 요청 횟수·크기 제한, 원본 robots.txt와 URL 검증

공개 조회는 사용자 요청대로 유지합니다. 직원 코드 로그인·정기 자동 전체 갱신은 추가하지 않았습니다. 전체 저장 목록 수집은 브라우저가 후속 요청을 보내므로 창을 닫으면 멈출 수 있습니다.

## 운영과 한계

Vinext/Cloudflare Workers와 D1 `DB`를 사용합니다. `drizzle/` 마이그레이션을 순서대로 적용합니다. v3는 DB 스키마를 추가 변경하지 않습니다. `.openai/hosting.json`의 기존 사이트 ID·운영 소유자 설정을 보존해야 합니다.

실시간 비교는 선택한 원본 카테고리 전체 페이지의 조회 시점 결과입니다. 거래처 계약 가격·로그인 전용 가격은 포함하지 않습니다. 같은 분류라도 브랜드·중량·생산일이 다를 수 있으므로 동일 상품 최저가로 단정하지 않습니다. 원본 분류에 없는 부위를 넓은 이름 검색으로 대신하지 않습니다.

초기 60,250건은 2026-10-20 수집한 별도 참고 스냅샷입니다. 원본 분류 확인이 없는 과거 데이터는 비교에서 제외합니다. 금천 비공개·단위 불명 716건, 일품 표시 수량과 실제 목록 차이 142건은 초기 수집 당시 기록입니다.

ZIP은 소스·배포 빌드·초기 CSV 보관용이며 Windows 설치 프로그램이 아닙니다. 소유자 ID·토큰·쿠키·운영 관심 품목·개인 설정은 포함하지 않습니다.
