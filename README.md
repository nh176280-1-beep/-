# 한눈에 시세 — 최신 공개 앱

**[앱 바로 열기](https://daegu-meat-prices-nh176280.satinycandy2.chatgpt.site)**

이 저장소의 기본 브랜치는 현재 공개 배포한 클라우드 앱 소스입니다.
가격 조회·전체 검색·방문자별 관심 품목 저장은 로그인 없이 사용할 수 있습니다.
전체 가격 수집은 기존 소유자 계정으로 관리자 로그인 후 실행합니다.

## 다운로드

[앱 소스·배포 빌드·전체 가격 CSV ZIP](downloads/price-board-clean-backup-20261020.zip) — 약 5MB.
ZIP을 다운로드하고 압축을 푼 뒤 `앱열기.url`로 온라인 앱을 열거나,
`data/전체가격_60250건.csv`를 엑셀에서 확인하세요.
ZIP은 보관·개발·재배포용이며 Windows 설치 프로그램은 아닙니다.

## 현재 버전

- 비로그인 공개 조회와 브라우저 방문자별 관심 품목 저장.
- 금천미트 공개 API·일품한우 실제 상품 목록을 최대 4페이지 병렬 요청하고 묶음 저장.
- 작업 진행 위치를 DB에 저장하며, 실패한 묶음은 위치를 건너뛰지 않고 재시도.
- 전체 수집 검증을 통과하기 전에는 기존 가격을 유지.
- 실제 API 1,000건 단회 비교: 순차 17.2초 → 병렬 3.4초. 전체 수집 시간은 서버 상황에 따라 달라집니다.
- 자동 정기 갱신은 아직 설정되어 있지 않습니다.

초기 실제 가격 60,250건(금천미트 49,819건, 일품한우 10,431건)이 `lib/seed.ts`에 포함돼 있습니다.
금천미트 비공개·단위 확인 불가 716건은 제외했습니다.
일품한우 원본 표시 수량과 실제 목록의 차이 142건은 일부 수집으로 표시합니다.
이 가격 스냅샷은 2026-10-20 수집 데이터이며, 이후 온라인 DB 갱신이 Git 파일에 자동 반영되지는 않습니다.

## 개발 및 재배포

Node.js 24 LTS와 npm을 사용합니다.

```sh
npm ci
npm run build
```

런타임은 Vinext/Cloudflare Workers이고, `DB` D1 바인딩을 사용합니다.
`drizzle/`에는 DB 마이그레이션, `tests/`에는 병렬 수집·공개 접근 검증이 있습니다.

```sh
node tests/collector.test.cjs
node tests/public-access.test.cjs
npx tsc --noEmit
```

일반 정적 HTML이나 Windows 실행 파일이 아니므로 빌드 파일을 더블클릭해서 실행할 수는 없습니다.
새 환경에는 DB 마이그레이션·초기 가격 적재·소유자 권한 구성이 필요합니다.
기존 서비스의 소유자 ID, 관심 품목, 계정·세션·토큰은 저장소와 ZIP에 포함하지 않았습니다.
`.openai/hosting.json`은 기존 Sites 앱 식별 정보를 보존합니다. 새 앱 생성 시 기존 ID를 재사용하지 마세요.

## 정리된 이전 파일

이전 PC 서버 앱, Windows 실행 패키지, 비밀번호 재설정 패키지, 가상 가격 체험 화면,
중복 스크린샷과 오래된 Render 안내는 현재 트리에서 제거했습니다. 과거 버전은 Git 이력에서 복구할 수 있습니다.
개발 캐시, 의존성 설치 폴더, 로컬 DB, 로그와 인증 파일은 추적하지 않습니다.
